# Proposal Structure Prompt
## Build the 7-Element Proposal Skeleton

**Use this prompt in Claude or ChatGPT AFTER running the Discovery Prompt.**

---

```
You are a proposal architect. I have completed a client discovery and extracted the following data:

STATED PROBLEM: [paste from Discovery Prompt output]
HIDDEN PROBLEM: [paste from Discovery Prompt output]
SUCCESS METRIC: [paste from Discovery Prompt output]
BUDGET SIGNAL: [paste from Discovery Prompt output]
URGENCY: [paste from Discovery Prompt output]

Write a proposal using the 7-element anatomy. Follow these rules:

1. THE HOOK: Lead with the hidden problem, not the stated problem. (2 sentences max)
2. THE DIAGNOSIS: Restate the client's situation using their own words from the brief. (3-4 sentences)
3. THE MECHANISM: Explain your process in 3 steps. Use active verbs. No jargon. (4-5 sentences)
4. THE PROOF: Cite one relevant result. If you have no client history, use a personal project or a hypothetical with specific numbers. (2 sentences)
5. THE SCOPE: List exact deliverables with deadlines. Use bullet points. (5-7 bullets)
6. THE PRICE: Give a single number for the recommended tier. Justify it in one sentence by linking it to the success metric. (1 sentence)
7. THE NEXT STEP: Give one specific action. "Reply to this email with 'YES' and I'll send the contract." (1 sentence)

Tone: Confident but not arrogant. Expert but not condescending. Like a doctor giving a diagnosis, not a salesperson giving a pitch.

Length: 300-400 words total. No filler. No "I hope this finds you well." No "Please let me know if you have any questions."
```

---

## Why This Works

The 7-element anatomy mirrors how the human brain makes buying decisions:
- **Hook** = Attention (the amygdala)
- **Diagnosis** = Trust ("This person gets me")
- **Mechanism** = Credibility ("This person knows how")
- **Proof** = Safety ("This person has done it")
- **Scope** = Clarity ("I know what I'm buying")
- **Price** = Value ("This price makes sense")
- **Next Step** = Action ("I know what to do")

Miss any element, and the brain says no. Include all 7, and the brain says yes — often before the client even realizes they've decided.
